## 适用范围

本政策适用于 **bingqilin456 的博客**（以下简称"本站"）。本站是个人博客，用于发布和分享内容；不提供账户注册、支付、定位或广告投放服务。访问本站、发表文章评论或在留言页留言前，请阅读本政策。

## 信息收集与使用

本站只在提供内容与评论功能，以及维护站点安全所需的范围内处理信息。

- **访问与统计信息**：本站当前未接入访问统计服务，不会为此主动收集访问数据。日后启用统计时，会在本政策中列明服务方及其处理范围。
- **评论与留言内容**：本站的评论区（含留言页）由 **giscus** 提供，评论与留言实际保存在 **GitHub Discussions**。发表评论或留言**必须通过 GitHub 授权登录**，本站不提供匿名发表。提交的内容、GitHub 账号的公开信息（如用户名与头像）以及时间信息会在对应讨论中公开显示。这些内容由 GitHub 存储，本站不保存评论正文的副本。
- **登录与凭证**：登录由 GitHub 完成授权，本站不接收您的 GitHub 密码或访问令牌，也无法以此登录您的 GitHub 账号。
- **浏览器本地数据**：按 giscus 官方说明，其客户端脚本会在本站在您浏览器中的本地存储（localStorage）读写会话数据，并在会话失效或过期时自动删除这些数据。该数据保存在您的浏览器中，不由本站服务端收集。

请不要在评论或留言中提交身份证件、银行卡、住址、密码或其他不必要的敏感个人信息。

## 第三方服务

配置完成后，为实现评论功能，以下第三方会在各自服务范围内处理相关数据：

- **[GitHub](https://github.com/)**：评论与留言的实际存储位置（GitHub Discussions）及登录授权方。发表评论需要登录 GitHub；账号与内容的处理适用 GitHub 自身的隐私声明。
- **[giscus](https://giscus.app/)**：评论区的嵌入组件。配置完成后，页面会加载来自 `giscus.app` 的客户端脚本、样式与 iframe；脚本会读取页面地址用于匹配对应讨论，并在您的浏览器本地存储中维护会话状态。
- **[Cloudflare](https://www.cloudflare.com/)**：可为本站提供静态资源分发和域名基础设施。

未配置评论仓库之前，本站不会请求上述评论相关的第三方资源。本站当前也未接入访问统计服务；日后启用时会先更新本政策并在此列出。

第三方服务可能有独立的隐私政策和数据保存规则。请在使用相关功能前查阅其规则；本站无法控制其独立的数据处理活动。

## Cookie 及本地存储的使用

本站主要使用浏览器本地存储（Local Storage 或 Session Storage）保存使用偏好，例如主题颜色、明暗模式、文章列表视图和音乐播放设置。

配置评论功能后，giscus 的客户端脚本可能在您的浏览器本地存储中读写评论会话数据（并在失效时清理），GitHub 的登录状态由其自身管理。这些数据保存在您的浏览器或 GitHub 侧，本站服务端不保存您的评论草稿或登录凭证。

本站不主动设置用于广告定向的第一方 Cookie。评论、统计或资源服务可能按照其自身规则使用 Cookie 或类似技术。您可以通过浏览器设置查看、删除或限制 Cookie 和本地存储；清除后，部分偏好可能会恢复为默认值，也可能需要重新登录 GitHub 才能继续评论。

## 信息公开、保存与安全

评论和留言属于公开互动内容，提交后可能被搜索引擎收录、被他人引用或在缓存中短暂保留。请谨慎决定发布内容。除非您提出删除请求、内容违反规则或法律法规另有要求，公开内容会持续保留以维持讨论上下文。

本站会采取合理措施保护数据安全，包括使用 HTTPS、输入校验、内容转义和访问频率限制。但互联网传输和第三方服务均无法保证绝对安全，请理解并自行承担公开发布信息的相应风险。

您可以通过 **GitHub（bingqilin456）** 联系我，说明需要处理的内容（例如某个讨论下的评论或留言）。需要说明的是：评论与留言的实际数据存放在 GitHub Discussions 中，因此查询、更正与删除主要由 GitHub 的机制完成，并由您本人或作为仓库所有者的站长执行，本站无法直接编辑 GitHub 上的内容。

对于由 GitHub、giscus 或 Cloudflare 独立处理的数据，您也可以直接向对应服务提供方行使相关权利。内容删除后，第三方缓存、搜索引擎索引或他人转载的副本可能无法立即同步删除。
